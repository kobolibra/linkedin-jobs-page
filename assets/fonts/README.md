# Finance Title SC

Four-glyph subset of Adobe Source Han Serif SC SemiBold (weight 600), for the masthead text 金融职位 only.

Source: https://github.com/adobe-fonts/source-han-serif/blob/release/OTF/SimplifiedChinese/SourceHanSerifSC-SemiBold.otf

The subset is renamed Finance Title SC, preserves the source copyright notice, and is distributed under the accompanying SIL Open Font License 1.1. Other page text does not use this font.

Build: fontTools subset with text='金融职位', WOFF output, desubroutinize=True; rename family/full/PostScript names and CFF names to Finance Title SC / FinanceTitleSC-SemiBold. Final size: 3,408 bytes.
